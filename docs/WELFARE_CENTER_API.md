# 福利中心接口

对标站接口为 `rewards_catalog`，当前项目对应：

```text
POST /api/user/rewards
```

请求体：

```json
{}
```

返回结构：

```jsonc
{
  "c": 0, // 0 成功，非 0 失败
  "m": "", // 提示信息
  "d": [
    {
      "key": "checkin", // 每日签到
      "rewards": [5, 15, 30, 15, 20, 25, 60], // 签到周期内每天的金币；页面显示最小值 5 至最大值 60
      "milestones": {
        "30": 500 // 连续签到 30 天额外奖励 500 金币
      }
    },
    {
      "key": "streak", // 连续追剧
      "cap": 3, // 每日基础奖励金币
      "milestones": {
        "30": 300 // 连续追剧 30 天额外奖励 300 金币
      }
    },
    {
      "key": "invite", // 邀请好友
      "cap": 80, // 好友首次充值后邀请人获得的金币
      "purchase_pct": 15 // 好友后续充值返佣比例；15 表示 15%
    },
    {
      "key": "share", // 每日分享
      "cap": 10 // 每日分享奖励金币
    },
    {
      "key": "rating", // 给剧评分
      "cap": 3, // 每部剧评分奖励金币
      "count": 5 // 每天最多奖励的评分部数
    }
  ]
}
```

福利中心只展示以上五项。`comment`（每日评论）和 `level`（升级奖励）不返回、不展示。

`/api/user/tasks` 继续负责当前账号状态，例如评分任务的 `left`、`done` 和 `earned`。
